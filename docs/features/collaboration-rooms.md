# Collaboration Rooms

A Collaboration Room is a scoped, expiring workspace for exactly one collaboration between an owner and their invited collaborators.

## What it enables

- One room per collaboration, rather than a standing bilateral data-sharing pipeline — create a room, run the analysis, let it expire.
- Per-collaborator query permission tiers, so a room owner can grant a partner overlap-only access without exposing row-level data, or the reverse.
- A single place to see every dataset and every task tied to a specific collaboration, for both participants.

## How it works

Rooms are created with a name, description, and expiry date; collaborators are invited by company email and must accept before they can act in the room. See [Collaboration Rooms](/overview/collaboration-rooms) for the full structure, and [Creating a Collaboration Room](/how-to-guide/creating-a-collaboration-room) to set one up.

## Who uses it

Every use case in this documentation — from [Telecom Fraud Detection](/use-cases/telecom-banking-fraud-prevention) to [Customer Overlap & Marketing Analytics](/use-cases/customer-overlap-marketing-analytics) — runs inside a Collaboration Room.
