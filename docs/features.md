# Features

PryvX's core platform capabilities:

- [Collaboration Rooms](/features/collaboration-rooms) — expiring, permissioned rooms for a single collaboration
- [Local PII Hashing Tool](/features/local-pii-hashing) — hash or remove PII before data ever reaches PryvX
- [Multi-Cloud Dataset Connections](/features/multi-cloud-dataset-connections) — upload a CSV, or connect GCS, AWS S3, or Azure Blob
- [No-Code AI Query Builder](/features/no-code-ai-analysis) — build a task visually, or describe it in plain language

See also [Use Cases](/use-cases) for how these are applied by industry, and [Solutions](/solutions) for the one-page summary.
