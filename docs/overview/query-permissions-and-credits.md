# Query Permissions & Credits

Two mechanisms bound what a collaborator can actually do inside a room: **query permissions**, set per collaborator, and **credits**, metered per account.

## Query permission tiers

When the owner invites a collaborator (or adds one later), they choose one or more of three permission tiers:

| Tier | Intent |
| --- | --- |
| **Overlap Insight** | The collaborator can run tasks that measure overlap between datasets (for example, matching counts on a hashed join key) without exposing individual records. |
| **Aggregate Insight** | The collaborator can run tasks that return aggregated results (counts, sums, averages) over the room's data. |
| **Individual Insights** | The collaborator can run tasks that return row-level results from the room's data. |

A collaborator can hold more than one tier at once. Permissions are set when they're invited and can be extended later from the room's Collaborator tab.

## Credits

Every PryvX account starts with a pool of free credits. **Running a task consumes one credit**, whether the task was built manually or generated by the AI suggestion feature — creating or editing a task costs nothing, only running it does. If an account's credit balance reaches zero, task runs are blocked platform-wide with a message to contact `hello@pryvx.com`; there is currently no self-serve way to purchase additional credits.

PryvX also tracks, per account, the total number of queries created and the total number of rows processed across all successful runs — this is what feeds the [audit & compliance report](/how-to-guide/exporting-insights/generating-an-audit-compliance-report).
