# Use Cases

Real-world applications of PryvX across regulated industries:

- [Telecom–Banking Fraud Prevention](/use-cases/telecom-banking-fraud-prevention) — SIM fraud, mule accounts, identity theft
- [Private Credit Scoring](/use-cases/private-credit-scoring) — combine financial and alternative data securely
- [Threat Intelligence Sharing](/use-cases/threat-intelligence-sharing) — joint analysis without compromising confidentiality
- [IoT & Cybersecurity](/use-cases/iot-cybersecurity) — federated learning across devices

Each use case is built on the features described in [Features](/features) and the platform mechanics in [Overview](/overview).
