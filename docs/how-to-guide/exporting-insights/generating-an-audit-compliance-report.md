# Generating an Audit & Compliance Report

The **Report** page produces a PDF summary covering one or more Collaboration Rooms over a chosen date range — useful for internal compliance review or sharing with a regulator.

## Steps

1. From **Report** in the sidebar, enter a **name** for the report.
2. Choose a **From** and **To** date.
3. Under **Collaboration Room**, select one or more rooms you own or collaborate on that fall within that date range — the list only shows rooms whose creation or expiry date overlaps the range you picked.
4. Select **Generate Report**. PryvX produces a PDF, which downloads automatically.

## What determines which rooms are selectable

A room appears in the picker if its creation date or expiry date falls inside the chosen From/To range — so to cover a room's full lifetime, pick a range that spans both its creation and expiry dates.

## When to use this

Generate a report whenever you need a point-in-time, shareable record of what collaborations were active and what was run in them — for example, ahead of an internal audit, or when a regulator asks what cross-party analyses your organization has run in a given period.
