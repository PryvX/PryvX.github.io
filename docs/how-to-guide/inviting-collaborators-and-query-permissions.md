# Inviting Collaborators & Query Permissions

Every collaborator beyond the room's initial invite list is added from the **Collaborator** tab, along with the query permissions that govern what they can do.

## Steps

1. From the room's **Collaborator** tab, select **Add Collaborator**.
2. Enter the collaborator's **company email**.
3. Choose one or more **Query Permissions**:
   - **Overlap Insight**
   - **Aggregate Insight**
   - **Individual Insights**

   See [Query Permissions & Credits](/overview/query-permissions-and-credits) for what each tier allows.
4. Select **Add Collaborator**. PryvX emails them a room invitation.

## Accepting an invitation

A newly invited collaborator sees the room with a `Pending` status and a prompt to accept the invitation before they can add data or create tasks. Once accepted, their status changes to `Approved` and they appear alongside the owner in the **Collaborator** tab.

## Changing permissions

Query permissions are set when a collaborator is added and can be extended later by adding them again with additional tiers selected. A collaborator's ability to add data (`Contribute Data`) is separate from their query permissions — every collaborator can contribute data, but only their granted tiers determine what kind of task results they can see.
